## OE levels

- Commitment: 457
- Achievement: 60
- Excellence: 17

## Five-point scoring scale
| Score | Label | Sample compliance range |
|---:|---|---:|
| 1 | No compliance | ≤20% |
| 2 | Poor compliance | 21–40% |
| 3 | Partial compliance | 41–60% |
| 4 | Good compliance | 61–80% |
| 5 | Full compliance | 81–100% |

Implementation is the basis for scoring. Inadequate/inappropriate system documentation could reduce the score by one.

## Assessment process
Submission of application → Desktop review → Optional pre-assessment → Final assessment → NABH Secretariat review → Accreditation Committee recommendation → Approval → Certificate (4 years) → Surveillance (21–24 months) → Renewal assessment. The book says renewal application is to be made six months before expiry.

## Accreditation decision — headline checks
**Final:** overall ≥80%; every Core OE ≥4; Commitment cumulative ≥80%; standard average ≥4; chapter average ≥4; no standard with more than one OE scored ≤2; accepted action plan/timelines for each OE scored ≤3.

**Surveillance:** overall ≥80%; Commitment and Achievement cumulative each ≥80%; improve prior OEs scored ≤2; every Core ≥4; standard/chapter averages ≥4; no standard with more than one OE ≤2; action plans for OEs ≤3.

**Re-accreditation:** overall ≥80%; Commitment, Achievement, Excellence cumulative each ≥80%; improve prior OEs scored ≤2; every Core ≥4; no OE in any standard scored ≤2; standard/chapter averages ≥4; action plans for OEs ≤3.

## Document hierarchy
1. Policy documents.
2. System documentation / SOPs.
3. Work instructions.
4. Forms, formats, and records.
5. External-origin documents (where the hospital includes them).

A completed record must not be altered. Controlled documents need clear identity, approval/review control, page numbering and authorisation. Keep current versions at points of use and remove obsolete copies.

## Important source limitation
The standards book says the detailed interpretation for each OE is in the separate **Guidebook to NABH Accreditation Standards for Hospitals — 6th Edition**. Do not invent official interpretations from the standards book alone. Clearly label practical implementation advice as a suggestion.
