# NABH Hospital Accreditation Expert Skill

This package contains a reusable skill definition and quick reference derived from the user-supplied NABH Hospital Accreditation Standards for Hospitals, 6th Edition (effective 1 January 2025).

- `SKILL.md`: skill instructions and operating rules.
- `NABH_6th_Edition_Quick_Reference.md`: chapter map, scoring, assessment thresholds, documentation principles, and source limitation.

The original NABH PDF is not redistributed in this package. Keep the supplied official PDF available as the primary source when using the skill. Detailed OE interpretations are stated in the separate NABH 6th Edition Guidebook, not in the standards book.
